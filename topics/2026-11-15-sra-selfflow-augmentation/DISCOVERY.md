## §1 我的猜测（2026-11-15，阶段 S1，AskUserQuestion 选项原话）

- Q1：toy 中把双时间步下不同噪声水平 token 之间的注意力完全切断，生成质量落在哪里？ → A：“比不切断更好”
- Q2：训练集从 64 条加到 4096 条，“双时间步相对单一时间步的收益”怎么变？ → A：“收益逐渐变大”
- Q3：AS 下少数组比例从 0.25 提到 0.5，采样仍用完整注意力，质量怎么变？ → A：“基本不变”
- 用户开题时的话：“他发现的这个问题很直观简洁，但是却不知道怎么发现的，以及具体怎么做”

## §2 当时的共识

- REPA 用外部编码器（DINOv2）对齐 DiT 中间特征；SRA（本文作者前作）改为自对齐：EMA 教师的深层、低噪声特征监督学生的浅层、高噪声特征 [作者前作 SRA §2–3]。
- Self-Flow 沿用同一对齐损失，只把学生输入换成双时间步：随机 25% token 用另一个噪声水平，教师看两者中较干净的那个 [Self-Flow §3.3–3.4]。
- Self-Flow 对收益的解释是信息不对称：学生必须 “leverage the cleaner tokens to infer … the noisier tokens” [Self-Flow §3.4]，即更强的自监督；其表中 SRA 7.27 → Self-Flow 5.70 FID（4M 步）[Self-Flow Table 1]。

## §3 关键观察

1. **概念层面的观察**：Self-Flow 与 SRA 的差别只有学生输入（Fig 1 并排画出），而改输入等于改训练数据。原文写 DTS “changes the training data”，于是收益里有两个纠缠的因素：交互带来的自监督、异质噪声带来的增强 [原文 §3，高]。
2. **实验层面的惊讶**：保留异质噪声输入、切断跨噪声注意力后，性能不降：SiT-B 800K 步 FID 25.19 → 25.06，IS 66.75 → 72.94 [原文 Table 1，高]。摘要里唯一的 “Surprisingly” 就在这里。

## §4 推理链

| 环节 | 内容 | 证据 | 置信度 |
|---|---|---|---|
| 观察 | Self-Flow = SRA 损失 + 换了学生输入；作者是 SRA 原作者，把新方法和自己的方法做“逐行 diff”最自然 | [原文 Fig 1、§1]；“作者因此做 diff”是 [推断] | 高 / 低 |
| 疑问 | Self-Flow 的机制（干净 token 引导嘈杂 token）只是叙述，没被干预实验检验过；而且 Self-Flow 自己报告不加表征损失、只用 DTS 也略有提升，这份收益没有自监督损失可归因 | [原文 §1 提问句]；[Self-Flow §3.3]；“作者用了后一条线索”是 [推断] | 高 / 低 |
| 假设 | DTS 的收益主要来自沿噪声维度扩大训练分布（噪声状态增强），不来自跨噪声 token 交互 | [原文 §1、§3] | 高 |
| 可检验预测 | 若交互是机制，切断跨噪声注意力后收益应消失；若是增强，收益应保留 | [原文 §1：“If the gain remains…”] | 高 |
| 论文中的实验 | 2×2：{单, 双时间步} × {完整注意力, AS}，SiT-B/ImageNet-256，FID-10K/IS，100K–800K 步（Table 1、2、Fig 4）；mask 比例 0.25/0.35/0.5（Table 3）；混入 ρ=0.25 的整图样本（Fig 5） | [原文 §5–6] | 高 |
| 方法 | 最终方案 = SRA 对齐 + DTS + AS，三者都保留；AS 自身被重新解释为“把一张图拆成多个局部视图”的增强 | [原文 §6–7] | 高 |

**具体怎么做**（代码层面，[官方代码]）：
- 每张图随机取恰好 ⌊α·N⌋ 个位置为第 0 组；DTS 开启时每组独立采样 t（uniform），两组共用同一份噪声。
- 时间步不加到 token 上，只进入条件向量：逐 token 的 t 嵌入 → 逐 token adaLN（每个 block 和 final layer）。
- AS 是一行掩码 `group[:, :, None] == group[:, None, :]`，在所有 block 的 softmax 前把跨组 logit 置为极小值；只在训练时用，采样走完整注意力。
- 训练脚本里教师也带同样的分组与 AS，教师各组时间步为学生的 t 减去 U(0, 0.2)（`teacher_t=sra`）；对齐为 cos、学生第 3 层 → 教师第 8 层（SiT-B）、权重 0.5、全部 token 都算。
- 代码支持任意多组、`teacher_t` 有三种、有 `full_sample_prob`：这些开关是探索过程留下的痕迹 [推断，低]。

## §5 备选发现路径

- **先有方法、后补叙事**：作者可能先在自己的 SRA 代码里试“分组注意力”（类似 MAE 式的局部视图或省算力的尝试），发现不掉点甚至涨 IS，再回头把它讲成对 Self-Flow 机制的检验。依据：代码是通用的多组实现；“AS 自身也是增强”这一解释（§6）两种假设事先都没预言，像事后归纳。可能性较低的理由：引言先提问再给实验，且 AS 作为“切断通路”的干预与问题严丝合缝；但无法排除 [推断]。
- **从复现失败出发**：作者复现 Self-Flow 时发现 SiT-B 上 DTS 的收益只有约 1 个 FID，远小于叙述给人的印象，从而怀疑机制 [推断，低；无直接证据]。

## §7 揭晓对照

- Q1“比不切断更好”：与论文方向一致，但论文里 FID 只好 0.13（100K 时还略差），明显的是 IS。toy 能否分辨要看 seed 间范围。
- Q2“收益逐渐变大”：论文没测。按“数据增强”的字面含义，数据越多增强越不重要，预期应是收益缩小；你的预测与假设的推论相反，这正是 E2 要判定的。漏掉的线索：把一个解释当真，就要问它还预言了什么。
- Q3“基本不变”：与论文 Table 3 相反（α=0.5 时 AS 的 FID 从 25.06 恶化到 38.19）。漏掉的线索：AS 只在训练时用，α=0.5 时模型从没见过超过一半 token 互相可见的情形，而采样时全部可见。
